# Facts are bi-temporal files, never overwritten

Agent memory tools such as mem0 and Graphiti keep facts in a service or a graph database and update them in place or behind an API. Dayfile keeps facts in `memory/<topic>.md`, which is the source of truth, and the SQLite table is rebuilt from those files. A fact is never changed or deleted to record news: it carries when it was true and when the journal learned it, a newer fact ends it, and a mistake is retracted. We chose this because the journal's promise is that a person can read and correct what their agent believes, and that "what was true then" and "what did the journal believe then" both stay answerable. The price is that files grow, conflict resolution is left to whatever syncs the folder, and semantic search over facts would have to be built on top. Changing the shape later means migrating files users own, so treat it as format, not implementation.
